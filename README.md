# 菇林弹丸 / Shroom Shot

Q 版打枪 roguelite：小狐狸猎人 vs 蘑菇怪。

一次远征，一条随机的路。

## 玩法

- **WASD** 移动，鼠标瞄准射击，**空格** 闪避，**Esc** 暂停
- 手机：左摇杆移动，右摇杆瞄准开火
- 远征图随机选路：战斗 / 精英 / 遗物 / 天赋
- 三王：大王菇、花冠菇、夜孢君（各三阶段，锁血变身）
- 本地存档，可继续远征

## 运行

```bash
npm install
npm run dev
```

浏览器打开提示的地址即可。生产构建：`npm run build`。

## 技术

Phaser 3 Arcade · TanStack Start · Zustand · Tailwind v4
